# Minimal input examples

These lightweight files demonstrate accepted input shapes:

- `compounds.csv` and `disease_genes.tsv`: required run inputs;
- `drug_targets.json` and `target_mapping.tsv`: optional provided-target boundary;
- `TPM_matrix_1.tsv` and `metadata_1.tsv`: optional paired Enhanced-mode expression inputs.

They are validation fixtures, not a validated disease model, benchmark dataset, or clinical
evidence. Running the full Workflow still requires the scientific resources and compute environment
described in `docs/RESOURCES.md`.
